# Miumi Friendship Garden

Create a fully functional, mobile-first cute quiz web app called miumi ♡.

DESIGN & AESTHETIC
I want a dreamy, whimsical, coquette and kawaii aesthetic.

Baby pink, blush pink, pastel rose and cream color palette.

Cute bows, hearts, flowers, sparkles and tiny stars.

Rounded cards, soft shadows and smooth animations.

Beautiful typography and adorable illustrations.

Make it look like a premium, professionally designed girly app.

Avoid generic templates and boring layouts.

HOMEPAGE

App name: miumi ♡

Welcome text: "Welcome to your little world!"

Subtitle: "Friendship, fun and little discoveries ♡"

A cute welcome illustration.

Interactive quiz category cards.

A daily question section.

Cute bottom navigation.

MAIN FEATURES

Friendship Quiz

Questions like "How well does your bestie know you?"

Multiple-choice answers.

Calculate final scores.

Show fun friendship results.

Personality Quiz

Fun personality questions.

Different personality outcomes.

Cute personalized result cards.

This or That

Two options per question.

Users select their favorite.

Show their final choices.

Bestie Challenge

Fun questions for friends.

Questions about favorite things, memories and preferences.

Daily Question

Display a fun question every day.

Results

Beautiful result screens.

Share results using native device sharing where available.

Copy results as a fallback.

Restart quiz functionality.

FUNCTIONALITY

Every button must work.

Quizzes must be interactive, not static mockups.

Add progress indicators.

Add back and restart buttons.

Include smooth page transitions.

Make everything responsive on mobile and desktop.

No login, no registration, no accounts.

No payments or subscriptions.

No unnecessary backend or database.

FINAL INSTRUCTION

Build the actual working application, not just a visual mockup. Prioritize a beautiful homepage, functional quizzes and delightful user experience.

The app should feel like a magical little pink friendship playground that people love exploring!
